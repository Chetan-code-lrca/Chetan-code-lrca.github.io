Privacy Policy

Last updated: 24 September 2026
TechSideHustle is a project/brand operated for personal development and experimentation. This policy describes the website and the connected automation tooling used with the TechSideHustle Pinterest account.

1. Information handled by the project

Depending on which features are enabled, the automation system may handle Pinterest account and board information, Pin content and media, publishing status, operational logs, and data needed to connect approved third-party services.

2. Pinterest data

The Pinterest automation can use authorized Pinterest API access to read the account's boards and perform permitted Pin operations. API access is intended for the account owner and is only used for the features enabled in the project.

3. Other service providers

Optional integrations can include AI content generation services, image-generation services, Amazon product data services, and scheduling or affiliate services. Only the integrations that are explicitly configured are used.

4. Credentials and secrets

API keys, OAuth tokens, passwords, and other credentials are configuration secrets. They are intended to be stored in environment variables or GitHub Actions secrets, not in source code. The public repository does not intentionally contain live credentials.

5. Local and operational data

The automation software may store application data such as trends, generated content, Pin metadata, job state, publishing events, and analytics in its configured database or local storage. Retention depends on the deployment configuration.

6. Website data

This website is a static GitHub Pages site. It does not provide a public login, payment system, or user account system. No form on this site intentionally collects personal information.

7. Security

Reasonable measures are used to avoid exposing application secrets, including keeping credentials out of source control and using secret stores for automated deployments. No online system can guarantee absolute security.

8. Third-party services

Pinterest, GitHub, OpenAI, Amazon, and any other enabled provider process information under their own terms and privacy policies. Their data handling is outside the control of this static website.

9. Changes to this policy

This policy may be updated when the project adds or changes integrations. The latest version will remain available at this URL.

10. Contact

For project-related questions, use the GitHub profile.
